# Project Rules

Before modifying this repository, read and follow:

- AGENTS.md
- 01-PRD.md
- 02-Business-Rules.md
- 03-Functional-Requirements.md
- 04-UX-Flows.md
- 05-Data-Model.md
- 06-Acceptance-Criteria.md

AGENTS.md is the universal project-level instruction.

Do not silently change approved requirements or business rules.

For non-trivial tasks:

READ → PLAN → IMPLEMENT → TEST → VERIFY → REPORT

When requirements are ambiguous, ask for clarification rather than
inventing business behavior.

Keep implementation simple and appropriate for the MVP.
