IMPLEMENTATION:
Perubahan dilakukan pada 4 file:

1. `src/ui/components/Card.tsx` — Ubah `children` dari `ReactNode` (wajib) menjadi `ReactNode?` (opsional).
   Logika render sudah menggunakan `{children ?? null}` yang aman untuk undefined.
   Keputusan: Card secara desain boleh tidak memiliki children; Card dapat berfungsi sebagai
   informasi container (hanya title/subtitle) tanpa konten tambahan.

2. `src/ui/providers/AppProvider.tsx` — Tambahkan suppression ESLint `react-hooks/set-state-in-effect`
   untuk baris `setState({ status: "loading" })`. Alasan: setState synchronous diperlukan agar
   retry ("Coba lagi") segera menampilkan loading state sebelum async operation (openDatabase,
   migrate) selesai. Tanpa setState ini, UI mempertahankan state "ready"/"error" dari prev attempt
   selama async berjalan, sehingga pengguna tidak dapat feedback bahwa operasi sedang berlangsung.
   Perubahan hanya pada komentar suppression, tidak mengubah behavior.

3. `src/app/products/[id].tsx` — Tambahkan `setLoading(true)` di awal `load()` agar
   re-fetch mereset loading state sebelum fetch berikutnya, sesuai guardrail persetujuan
   user. Alasan: `load()` dapat dijalankan kembali ketika dependency berubah (id/products/
   replaceValues) dan loading state perlu di-reset sebelum fetch berikutnya. Tanpa reset ini,
   re-fetch tidak akan menampilkan loading indicator. Suppression ESLint tetap dipertahankan
   untuk pemanggilan `void load()` dalam useEffect karena lint rule dipicu oleh pola ini.

4. `src/app/agents/[id].tsx` — Sama seperti products/[id].tsx: tambahkan `setLoading(true)`
   di awal `load()` + suppression untuk pemanggilan `void load()`.
